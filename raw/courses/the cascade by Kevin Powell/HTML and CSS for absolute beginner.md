## Components of a Web Page:

- [[HTML]]: HTML stands for Hypertext Markup Language.
  - It is the language we use to provide the content for the websites and web apps.
- [[CSS]]: CSS stands for Cascading Style Sheets.
  - It is the language that we will use to style the content on the page. It’s responsible for everything from changing the color of the text to controlling the layout of the page.
- [[JavaScript]]: JavaScript is the language that is responsible for adding interactivity, like opening menus, those wonderful “subscribe to our newsletter” popups, handling dynamic content, and much more.
