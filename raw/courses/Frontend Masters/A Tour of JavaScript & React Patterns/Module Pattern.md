- A module in [[JavaScript]] is a file containing code and makes it easy to expose or hide values.
- The Module Pattern is a pattern do divide your code into smaller and reusable pieces which can be imported and used in other parts of the application. It also promotes code [[Encapsulation|encapsulation]], since the values within a [[JavaScript ES6 Modules]] are kept private by default.
  - Only the values exported with the `export` keyword are accessible to other files.
