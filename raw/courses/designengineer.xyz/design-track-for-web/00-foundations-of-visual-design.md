## What is Visual Design?

- Visual Design is the strategic use of imagery, color, typography and space to guide users and communicate meaning.
- It's a system for visual communication.
- It accounts for different screens, changing states and complex information hierarchy.
- It also works within [[Web Accessibility|accessibility]] and [[Web Performance|performance]] constraints.

## Graphics Design vs Visual Design

- **[[Graphics Design]]** focuses on visual content for communication e.g. logos, posters, ads, book covers etc.
  - A graphic designer creates a beautiful poster.
  - These are static content to be viewed but can't be interacted with.
- **[[Visual Design]]** in digital products focuses on how visual elements guide users through interactive experiences.
  - A visual designer creates an interface to help users accomplish their goal efficiently.

## Role of Visual Design

- Communication without words:
  - Decoration prioritizes aesthetics over clarity.
  - Communication prioritizes clarity, hierarchy and actionable feedback.
- Reducing cognitive load:
  - Good visual design reduces the mental effort required to use a product.
    - **How?**:
      - Logically organize visual elements
      - Consistent styling
      - Clearly differentiated
- Guiding attention
- Building trust:
  - Clear hierarchy, legible content and consistent behaviour can support credibility; misleading content or unreliable interactions will quickly undo it.
- Enabling usability

## Elements of Visual Design

![[Pasted image 20261004150735.png]]

- **Hierarchy**:
  - Visual weight and importance
  - Where should the user go first? Second? Third? And then lastly?
  - How does the arrangement guide their attention?
- **Contrast**:
  - The difference between elements in size, colour, weight, spacing.
  - Contrast creates emphasis and separation.
- **Balance**:
  - Consistency in visual treatment.
  - Repeating patterns help users learn interfaces and predict behaviour.
- **Alignment**:
  - The positioning of elements relative to each other.
  - Aligned elements feel connected and organised. Misaligned elements feel accidental.
- **Proximity**:
  - How close or far elements are from each other.
  - Proximity signals relationships. Things that are close together are perceived as related.
