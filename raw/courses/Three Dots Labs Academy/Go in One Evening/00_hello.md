```go
// package declaration
// the main package
package main

// importing dependencies
// format package: used to format text and display it
import "fmt"

// entry-point of a go application
func main() {
	fmt.Println("Hello, World!")
}
```

- Go code can be grouped into packages.
- You can use other packages by importing them.
